# موقع Kylixe: ملفات الموقع مع إدارة بنماذج (Pages CMS)

كل ما بدك تغيّره (صور الصفحة الأولى، المنتجات، الأسعار، الأسماء، الفئات، النصوص، الـ Impressum) صار من نماذج بسيطة، بدون ما تلمس الكود.

## 1) رفع الملفات على GitHub (مرة وحدة، من كمبيوتر)
1. فك ضغط `kylixe-site.zip`.
2. افتح مستودع `kylixe` على GitHub، ثم **Add file** ثم **Upload files**.
3. اسحب **كل** محتويات المجلد: `index.html` ومجلد `data` ومجلد `images` وملفات الأيقونات. (اسحب المجلدات نفسها).
4. اضغط **Commit changes**. هيك بيحلّ `index.html` الجديد مكان القديم.
5. الملف المخفي `.pages.yml` ما بيتسحب بسهولة، فأنشئه يدوياً: **Add file** ثم **Create new file**، سمّه `.pages.yml`، والصق فيه كل محتوى الملف `pages-config-for-copy.yml`، ثم **Commit**.
6. بعد دقيقة أو دقيقتين بيتحدّث الموقع على `kylixe-de.github.io/kylixe`.

## 2) تشغيل الإدارة
1. افتح https://app.pagescms.org وسجّل دخول بحساب GitHub.
2. اختر مستودع `kylixe`. بتظهر 3 أقسام: **Products** و**Categories** و**Site settings**.

## 3) شو بتعمل من الواجهة
- **تغيير صور الصفحة الأولى:** Site settings ثم Home page photos. بدّل الصورة أو أضف حتى 3 صور. خيار "Which part of the photo stays visible" بيحدد الجزء الظاهر من الصورة (يسار، وسط، يمين). إذا حطيت أقل من 3 صور، بيظهر رسم بدل الصورة الناقصة.
- **منتج جديد:** Products ثم Add an entry. عبّي الاسم بالإنجليزي والألماني والسعر والوصف، واكتب Category ID (مثلاً `vases`)، وارفع الصور. الـ ID اتركه فاضي وبيتعمل من الاسم.
- **تغيير الاسم أو السعر:** افتح المنتج وعدّل وسجّل Save.
- **إخفاء منتج:** طفّي مفتاح **Show on the site** بدون ما تحذفه، ولما بدك ترجّعه شغّله.
- **صور المنتج:** أول صورة هي الرئيسية (بتظهر بالقائمة). الصورة اللي خلفيتها مقصوصة (PNG أو WebP شفاف) فعّل عليها **cutout**. الصورة العادية اتركها بدون تفعيل.
- **فئة جديدة:** Categories ثم Add an entry. الـ ID بحروف إنجليزية صغيرة وشرطات (مثل `gifts`). وبعدها استعمله بحقل Category ID بالمنتجات. إذا ما حطيت صورة، بيرسم الموقع شكل جاهز اخترته من القائمة.
- **إخفاء فئة:** طفّي **Show on the site**، وبتختفي هي ومنتجاتها.
- **ملاحظات أخرى:** رقم الواتساب واسم حساب إنستغرام وروابط المنشورات والشحن والـ Impressum كلها بـ Site settings.
- **بعد الحفظ:** بيتحدّث الموقع بعد دقيقة تقريباً. إذا ما شفت التغيير، حدّث الصفحة بقوة أو افتحها بنافذة خاصة.

## ملاحظات مهمة
- لو فتحت `index.html` مباشرة من جهازك (بدون استضافة)، بيظهر المحتوى الافتراضي، وما بتظهر تعديلاتك. هاد طبيعي.
- لازم يضل المجلدان `data` و`images` جنب `index.html`.
- الـ Category ID بالمنتج لازم يطابق ID فئة موجودة ومفعّلة، وإلا ما بيظهر المنتج.
- الخطوط (Quicksand و Montserrat) بتتحمّل من Google. لألمانيا الأفضل قانونياً تحميلها من موقعك أنت، وفيني أعملها لك بعدين.

## لوحة التحكم (الأسهل): `/admin`

بعد رفع الموقع، افتح: `https://kylixe-de.github.io/kylixe/admin/` (أو رابط موقعك + `/admin/`).

**أول مرة فقط، بتعمل مفتاح (Token):**
1. على github.com: Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Repository access: **Only select repositories** ← اختر مستودع الموقع فقط.
3. Repository permissions ← **Contents: Read and write**.
4. انسخ المفتاح والصقه بلوحة التحكم. بيتحفظ على جهازك فقط، لا تشاركه مع أحد.

**بعدها بتقدر:**
- المنتجات: إخفاء/إظهار بمفتاح، تعديل الاسم والسعر والوصف، رفع عدة صور وترتيبها، إضافة وحذف.
- الفئات، صور الصفحة الأولى (3 صور + الجزء الظاهر)، نصوص العرض، واتساب وإنستغرام، الشحن، Impressum.
- اضغط **حفظ ونشر** بالأسفل، والموقع بيتحدّث بعد حوالي دقيقة.

ملاحظة: صفحة `/admin` ما فيها أي بيانات سرية، والتعديل مستحيل بدون مفتاحك.
