# موقع Kylixe: الملفات ولوحة التحكم

## 1) رفع الملفات على GitHub
1. فك ضغط `kylixe-site.zip`.
2. افتح مستودع الموقع على GitHub ← **Add file** ← **Upload files**.
3. اسحب **كل** محتويات المجلد: `index.html` ومجلدات `admin` و`data` و`images` وملفات الأيقونات.
4. اضغط **Commit changes**. الملفات الجديدة بتحلّ مكان القديمة.
5. بعد دقيقة أو دقيقتين بيتحدّث الموقع.

## 2) لوحة التحكم: `/admin`
افتح `رابط-موقعك/admin/`.

**أول مرة فقط، بتعمل مفتاح (Token):**
1. على github.com: Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Repository access: **Only select repositories** ← اختر مستودع الموقع فقط.
3. Repository permissions ← **Contents: Read and write**.
4. انسخ المفتاح والصقه بلوحة التحكم. بيتحفظ على جهازك فقط، لا تشاركه مع أحد.

**شو بتقدر تعمل:**
- **المنتجات:** إخفاء أو إظهار بمفتاح، تعديل الاسم والسعر والوصف، رفع عدة صور وترتيبها، إضافة وحذف.
- **الفئات:** إضافة وتعديل وإخفاء. إخفاء فئة بيخفي منتجاتها.
- **صور الصفحة الأولى:** حتى 3 صور مع اختيار الجزء الظاهر.
- **النصوص والعرض، واتساب وإنستغرام، الشحن، Impressum.**
- اضغط **حفظ ونشر** بالأسفل، والموقع بيتحدّث بعد حوالي دقيقة.

## ملاحظات مهمة
- لازم يضل المجلدان `data` و`images` جنب `index.html`.
- لو فتحت `index.html` مباشرة من جهازك (بدون استضافة)، بيظهر المحتوى الافتراضي بدون أنيميشن الأيقونات وبدون تعديلاتك. هاد طبيعي.
- الـ Category ID بالمنتج لازم يطابق ID فئة موجودة ومفعّلة، وإلا ما بيظهر المنتج.
- لا تحذف ملف `CNAME` إذا ربطت دومين.
- الخطوط (Quicksand و Montserrat) بتتحمّل من Google. لألمانيا الأفضل قانونياً تحميلها من موقعك أنت.
- صفحة `/admin` ما فيها أي بيانات سرية، والتعديل مستحيل بدون مفتاحك.
